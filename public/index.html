Ramayana Book MCP Server

An MCP server for the Valmiki Ramayana: verse lookup, full-text search, and a verse of the day, across Sanskrit, English, Hindi, and Telugu translations.

Endpoint: https://ramayana-mcp.vercel.app/api/mcp

Tools

  • list_kandas - the seven kandas with chapter counts
  • get_verse - one verse by kanda, chapter, and verse number
  • get_sarga - every verse of one chapter
  • search_verses - full-text search across all four languages
  • verse_of_the_day - a deterministic verse for a calendar date

Health check: /api/hello
